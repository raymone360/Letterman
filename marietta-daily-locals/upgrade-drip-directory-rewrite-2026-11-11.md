# Marietta Daily Locals — Directory Upgrade Drip (rewrite, ready for approval)

**What this is:** the 5 automatic emails Letterman sends a free-listed business to offer the paid "featured" upgrade. The stock set is identical in all three areas (directory, hotspots, events), all switched OFF. This rewrite covers the **directory** set first — that's where your 7 home-services listings live.

**Settings found (keep as-is):** series OFF, 5 steps, gaps Day 0 / +3 / +4 / +5 / +7 (so emails land on days 0, 3, 7, 12, 19), every step active, **stop-on-upgrade ON** (a business that upgrades hears no more — keep that), sending configured and ready.

**Placeholders kept exactly as Letterman expects them:** `{{business_name}}`, `{{publication_name}}`, `{{category_name}}`, `{{upgrade_button}}`, `{{listing_link}}`, `{{signup_date}}`. No price is named in the emails — the upgrade button shows the exact cost before they commit, same as the stock approach.
